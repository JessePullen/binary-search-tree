# Project: Binary Search Tree

## About the Project
A JavaScript implementation of a Binary Search Tree built as part of The Odin Project.
This project implements a Binary Search Tree using JavaScript classes. The tree supports inserting, deleting, finding, and traversing nodes, as well as calculating node height and depth.
The project also includes functionality for checking whether the tree is balanced and rebalancing it when necessary.

## Skills Practiced
- Recursion
- Binary Search Trees
- Tree traversal algorithms
- Breadth-first traversal
- Depth-first traversal
- Test-driven development with Jest
- Private class methods
- Queues
